# 报告二：美学头与 LoRA 对比（eval）

- 日期：2026-11-10
- 要回答的问题：同一份 EVA 划分上，微调的美学头和 Qwen3.5-4B
  LoRA 打分谁更准、代价差多少。
- 评测集：eval 407 张，指纹 `fe56c426…11a3`，三个模型完全相同。
- 指标：SRCC / PLCC 对 EVA 投票均值，MAE 对 1–5 目标。
  `aes_head/metrics.py` 是主仓库指标代码的副本，测试会核对两边
  结果一致。三份报告的数字都用同一段代码从逐张预测重算过，
  与各自的 `report.json` 一致。
- 输入：两边都用原图尺寸。EVA 图在 44,064 到 640,000 像素之间；
  eval 里没有图超出 Qwen 的像素上下限（65,536 到 1,048,576）。

## 比的是哪三个

| 名称 | 模型 | 训练 |
| --- | --- | --- |
| 原版 + 提示词 | Qwen3.5-4B，提示词 `zero-shot-score@v2` | 否 |
| LoRA | Qwen3.5-4B + LoRA r16，同一提示词 | 是 |
| 美学头 | ConvNeXt-T 微调 + 两个回归头 | 是 |

- 结果文件（不入库）：
  - 原版：主仓库 `data/runs/b0-qwen35-4b-tune/`
  - LoRA：主仓库 `data/runs/eva-qwen35-4b-lora-r16-eval/`
  - 美学头：`runs/convnext-t-ft-eval/`
- 原版 + 提示词是提示词调优选出的最好单图提示词，在全量 EVA 上
  跑过，这里取其中 eval 的 407 张（`report-eval.json`）。
- LoRA 和美学头都只在 val 上选模，eval 各评一次。
- 美学头选中 `convnext-t-ft-lr1e-4-s1`，选法见报告一。

## 结果（eval，407 张）

| 模型 | 美学 SRCC | 美学 PLCC | 技术 SRCC | 技术 PLCC |
| --- | --- | --- | --- | --- |
| 原版 + 提示词 | 0.490 | 0.507 | 0.561 | 0.602 |
| LoRA | **0.810** | **0.834** | **0.764** | **0.789** |
| 美学头 | 0.768 | 0.775 | 0.722 | 0.740 |

- MAE（美学 / 技术）：原版 0.552 / 0.734，LoRA 0.173 / 0.166，
  美学头 0.197 / 0.188。
- LoRA 的解析成功率 100%；美学头直接输出数字，不用解析。

**同一批图上的配对差值**（SRCC，2,000 次配对 bootstrap）

| 对比 | 分数 | 差值 | 95% 区间 |
| --- | --- | --- | --- |
| LoRA 减美学头 | 美学 | +0.042 | +0.007 到 +0.080 |
| LoRA 减美学头 | 技术 | +0.042 | −0.001 到 +0.085 |
| LoRA 减美学头 | 均值 | +0.042 | +0.010 到 +0.075 |
| 美学头减原版 | 美学 | +0.279 | +0.194 到 +0.359 |
| 美学头减原版 | 技术 | +0.161 | +0.090 到 +0.230 |
| 美学头减原版 | 均值 | +0.220 | +0.153 到 +0.282 |

## 代价

| 项 | 美学头 | LoRA |
| --- | --- | --- |
| 参数 | 约 2,860 万（骨干 2,782 万，头 74 万） | 约 40 亿 + LoRA |
| 权重文件 | 检查点 114 MB（fp32） | 基座加 adapter |
| A10 每张 p50 / p95 | 5.4 / 6.4 ms（预热后） | 1,044 / 1,098 ms |
| 输出 | 两个分数 | JSON 文本，以后可加评语 |

- 美学头的 eval 报告写的是 p50 6.6 ms、p95 1,280 ms。慢的那些
  全是进程里第一次遇到的图片尺寸：255 种首次出现的尺寸里有
  199 张超过 100 ms，重复尺寸的 152 张没有一张超过。上表去掉了
  这 199 张（它们 323–1,474 ms，中位 961 ms）。部署时要么固定
  输入尺寸，要么接受每种新尺寸第一次慢约 1 秒。
- 本机 CPU 上 ConvNeXt-T 骨干每张约 406 ms（p50，探针时测，
  同机还在跑测试）。LoRA 在 CPU 上没测过。

## 结论

1. **LoRA 更准，两项都高约 0.04。** 均值差 +0.042，区间不含 0；
   美学分的区间也不含 0，技术分的下界刚好碰到 0。
2. **两条路线都远好于原版加好提示词。** 美学头比原版高 0.22
   （均值，区间远离 0），LoRA 高 0.26。项目要求训练后的模型
   要明显好过原版模型加好提示词，两者都满足；具体门禁阈值还没定。
3. **美学头小两个数量级、快两个数量级。** 参数约是 LoRA 的
   1/140，A10 上每张快约 190 倍。NAS 只有 AMD CPU，这个差距
   比 0.04 的精度差更可能决定能不能部署。
4. **取舍。** 要更准、要评语，选 LoRA；要在 NAS 上本地快速打分，
   美学头是现实的选择。最终还要看两者在 NAS 上的实测速度和内存。

## 局限与下一步

- eval 只有 407 张，0.04 的差距区间较宽。
- 美学头的学习率还在网格上沿（见报告一），继续调可能缩小差距。
- **两路平均（只作线索，不作结论）。** 写报告时顺手在 eval 上算
  了美学头和 LoRA 的分数平均：0.826 / 0.785，比 LoRA 单独高。
  这是看过 eval 之后才算的，不能当结果用；要采用的话，先在 val 上
  验证。
- NAS 上实测：美学头导出 ONNX 测 CPU 耗时；LoRA 4B 在 NAS 上
  能不能跑、多慢。
