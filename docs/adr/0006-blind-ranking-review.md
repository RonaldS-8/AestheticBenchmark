# ADR-0006：客户盲评：只看排序，不看分数

- 状态：已被 ADR-0011 取代（实现已归档到 `archive/video-dover/`）
- 日期：2026-11-02

## 背景

VLM 打 1–5 分，DOVER 的分数没有固定区间，还可能是负数，
两边的绝对值没法直接比。最终要判断的是哪一边的排序更符合
客户的审美。

## 决定

- 两边各自按分数从高到低排序，用 `scripts/render_ranking.py`
  生成一个独立的 HTML 评审包（页面加视频副本）发给客户。
- 盲评：页面上只显示“方案 A / 方案 B”和名次，不显示分数和运行名。
  哪一边是 A 由种子决定，对照表写在评审包外面，不发给客户。
- 客户逐个维度选“A 更合理 / B 更合理 / 差不多”，页面生成一段文字发回。
- 解析失败、没有分数的视频单独列出，不参与排序。

## 放弃的方案

- 把分数归一化后放在一起展示：会暴露哪边是哪个模型，
  而且归一化方式本身就会影响判断。
- 做在线问卷：需要服务端和账号，第一版用不上。

## 后果

- 评审包里有视频副本，发给外部客户前要确认视频授权允许这样使用。
- 视频多时页面会很长，建议先抽取几十个视频生成。
