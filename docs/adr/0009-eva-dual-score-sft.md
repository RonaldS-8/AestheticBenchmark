# ADR-0009：EVA 先做双分数弱监督 SFT

- 状态：已采纳
- 日期：2026-11-03

## 背景

项目最终输出是美学、技术、总体三项分数和一句评语。EVA 有同一张图
上的美学总分和技术质量分，但没有项目定义的总体分，也没有文字评语。

当前目标是先用已经取得的 EVA 数据训练 Qwen3.5-4B，不等待项目自建
人工标注。EVA 的分数本身来自受试者投票；这里“暂不使用人工分数”
指暂不接入本项目另行制作的 `AnnotationRecord`，不是丢弃 EVA 标签。

Qwen 官方仓库已核实：`Qwen/Qwen3.5-4B` 是图文模型，锁定 revision
`851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`。官方 chat template
接受本地图片项 `{"type":"image","image":"..."}`。

## 决定

- 第一阶段单独使用 EVA，训练目标只有 `aesthetic` 和 `technical`。
- 不用规则或模型补造 `overall`、`comment`，避免伪标签污染。
- 两项来源均值分别按原量表线性映射到 1–5，再保留一位小数：

  ```text
  target = 1 + 4 × (mean − scale_min) / (scale_max − scale_min)
  ```

- 每条 JSONL 保存 Qwen 消息、图片路径和哈希、原始均值、标准差、
  投票人数与 capture id，训练损失只计算 assistant token。
- Qwen3.5 使用非思考模式，chat template 参数固定为
  `enable_thinking=false`；模板 SHA-256 固定在数据清单中。
- v1 用种子 42 做确定性 80%/10%/10% 划分，eval 指纹写入清单。
- 生成目录只增不改；`data/manifests/eva/sft/v1/` 已存在时拒绝覆盖。

## 放弃的方案

- 把 EVA 美学分同时当成总体分：同一个标签重复承担两个定义，无法区分
  美学和总体，不采用。
- 根据两项分数计算总体分：项目规定总体分不是简单平均，不采用。
- 用模板或 LLM 自动生成评语：EVA 没有文字依据，且未经人工复核，
  不采用。
- 等项目人工标注全部完成后再训练：会推迟第一轮模型和数据管线验证，
  不采用。

## 后果

- 第一阶段模型只学习双分数 JSON，不是最终可部署的四字段输出模型。
- 后续需要用项目人工标注做第二阶段 SFT，切换到标准
  `AestheticOutput`，学习总体分和评语。
- 两阶段的提示词与输出契约分开版本化，评测时不能混用。
- EVA 原始标签和转换后目标都保留，可以审计量表映射与样本分歧。
