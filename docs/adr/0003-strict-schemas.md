# ADR-0003：数据与配置：严格 schema、JSONL、TOML

- 状态：已采纳
- 日期：2026-11-02

## 背景

数据要经过爬虫、标注、划分、训练、评测、导出多个环节，
由不同的人和工具处理。字段漏填、悄悄填默认值、评测集泄漏，
都会让结果看起来正常但实际不可信。

## 决定

- 所有记录用 pydantic 定义：不可变、拒绝未知字段、没有默认值。
  “没有这个值”必须显式写 `null`，不能省略，也不能当 0。
- 记录存成 JSONL，每行一条，带 `schema_version`；
  训练配置用 TOML，用标准库 `tomllib` 读取。
- 出错直接抛异常，不兜底、不修补数据。
- 基座模型、DOVER 代码锁定到 commit，文件锁定到 sha256；
  评测集用 `eval_fingerprint` 锁定。

## 放弃的方案

- dataclass 加手写校验：嵌套结构多，校验代码会比 schema 还长。
- YAML 配置：需要额外依赖，类型也更宽松。

## 后果

- 每改一次 schema 都要同步改 fixture 和测试，`SCHEMA_VERSION` 要跟着升。
- 数据问题会在最早的环节报错，不会拖到训练或评测阶段才暴露。
