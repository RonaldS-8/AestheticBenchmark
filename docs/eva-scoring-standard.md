# EVA 打分标准与标签统计

核对日期：2026-11-03。数据来源核对见 `source-review-eva.md`，
训练目标的决定见 ADR-0009。

## 1. 官方定义（作者 README 原文要点）

EVA 是在线主观实验：受试者看从 AVA 选出、缩放后的图片，每看一张
提交一票。`votes_filtered.csv`（分隔符 `=`）每行一票：

| 字段 | 含义 | 取值 |
| --- | --- | --- |
| `score` | 总体审美分（general score） | 整数 0–10，共 11 级 |
| `difficulty` | 这张图打分难不难 | 1 很难，2 难，3 容易，4 很容易 |
| `visual` | 光线与色彩 | 1 very bad … 4 very good |
| `composition` | 构图与景深 | 同上 |
| `quality` | 质量 | 同上 |
| `semantic` | 语义内容 | 同上 |
| `1`–`4` | 哪些属性影响了总分（多选勾选） | 0 / 1 |
| `vote_time` | 距上一票提交的秒数 | 实数 |

勾选框编号：1 光线与色彩，2 构图与景深，3 质量，4 语义。

- `votes_filtered.csv` 是作者过滤后实际使用的投票；`votes.csv`
  是未过滤的全部投票。
- 第三方综述把 `score` 描述为 0 最不美、10 最美；README 本身只写了
  “general score, integer in [0,10]”。
- **未核实**：具体过滤规则（剔除哪些受试者或投票）只在论文里，
  README 没写，本次没拿到论文全文。用过滤后数据不受影响，
  但引用过滤规则前要先读论文。

## 2. 本项目怎么用

| EVA | 项目字段 | 换算到 1–5 |
| --- | --- | --- |
| `score` 的图级均值 | `aesthetic` | `1 + 4 × mean / 10` |
| `quality` 的图级均值 | `technical` | `1 + 4 × (mean − 1) / 3` |
| 无 | `overall`、`comment` | 不生成（ADR-0009） |

换算结果保留一位小数作为 SFT 目标；评测相关系数对**原始均值**算，
不对四舍五入后的目标算。

注意：`technical` 来自受试者对“质量”的主观感受，不是客观 IQA
指标，而且和审美分高度相关（见第 4 节）。

## 3. 实测统计（`data/raw/eva/votes_filtered.csv`）

| 项 | 值 |
| --- | ---: |
| 投票 | 136,943 |
| 图片 | 4,070 |
| 受试者 | 1,094 |
| 每图票数 | 30–46，中位 33 |

单票分布：

- `score`：6 分和 7 分最多（各约 20%），0–2 分合计约 5%。
- `quality`：3 分（good）占 66%，1 分只占 2%。

图级均值：

| | 最小 | 中位 | 最大 | 标准差 |
| --- | ---: | ---: | ---: | ---: |
| `score`（0–10） | 1.76 | 6.15 | 9.03 | 1.02 |
| `quality`（1–4） | 1.44 | 2.90 | 3.59 | 0.27 |
| `aesthetic` 目标（1–5） | 1.7 | 3.5 | 4.6 | 0.41 |
| `technical` 目标（1–5） | 1.6 | 3.5 | 4.5 | 0.36 |

两个目标各只有约 30 个不同取值，都集中在 3.5 附近，约三分之二的图
落在 ±0.4 以内。

## 4. 标签间关系与可达上限

图级 SRCC（Spearman）：

| 对比 | SRCC |
| --- | ---: |
| `score` vs `quality` | 0.76 |
| `score` vs `visual` | 0.85 |
| `score` vs `composition` | 0.89 |
| `score` vs `semantic` | 0.87 |

分半一致性（每张图的票随机分成两半，种子 0，两半均值算 SRCC）：

| | 分半 SRCC | 全量估计（Spearman-Brown） |
| --- | ---: | ---: |
| `score` | 0.82 | ≈ 0.90 |
| `quality` | 0.72 | ≈ 0.84 |

这是模型 SRCC 的大致上限：美学分能做到 0.8 以上才算接近人群一致性，
技术分的上限更低、噪声更大。

## 5. 对训练与评测的影响

- 门禁看 SRCC / PLCC，不看 MAE：目标分布窄，预测全给中位数
  也能得到不错的 MAE。
- `technical` 与 `aesthetic` 相关 0.76，模型可能只学一个分数再
  复制；评测时单独看 `technical` 的 SRCC，并看两项预测之间的相关。
- 没用上的字段（三项属性、难度、影响因子勾选）以后可以做辅助
  任务或评语依据，第一阶段不用。
