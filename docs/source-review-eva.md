# EVA 数据源核对记录

核对日期：2026-11-02

## 结论

EVA（Explainable Visual Aesthetics）适合作为第一批研究数据：

- 同一条人工投票同时提供美学总分 `score` 和技术质量属性
  `quality`。
- 评分表和图片分卷可从作者公开仓库直接获取，不需要登录。
- 本次实测得到 4,070 张有过滤评分的图片、136,943 条投票。
- 只用于当前研究管线；仓库没有提供标准开源许可证，不能据此推断
  允许商用。

## 已核实事实

官方来源：

- 项目仓库：<https://github.com/kang-gnak/eva-dataset>
- 评分表：仓库中的 `data/votes_filtered.csv`
- 图片：仓库中的 `images/EVA_together.zip.001` 至 `.007`
- 论文：Chen Kang、Giuseppe Valenzise、Frédéric Dufaux，
  *EVA: An Explainable Visual Aesthetics Dataset*，2020，
  DOI `10.1145/3423268.3423590`

作者 README 明确说明：

- 图片是从 AVA 选取并缩放、展示给受试者的版本。
- `score` 是 0–10 的 general score。
- `quality` 是 1–4 的质量属性分；1 表示 very bad，4 表示
  very good。
- `votes_filtered.csv` 是作者过滤后实际使用的投票。
- 使用数据集时应引用论文。

Crossref 返回的论文元数据与 README 中的标题、作者和年份一致。

## 本项目的字段解释

以下是项目映射决策，不是论文原字段重命名：

| EVA 字段 | 项目字段 | 理由 |
| --- | --- | --- |
| `score` | `aesthetic` | 作者称为 general score，量表 0–10 |
| `quality` | `technical` | 独立的图像质量属性，量表 1–4 |
| 无 | `overall = null` | 不用美学分冒充项目的总体分 |

原始量表不在爬虫阶段换算。训练样本生成阶段如需统一到 1–5，必须按
`docs/training-data-design.md` 的线性公式转换并保留来源量表。

## 实际采集结果

本次运行得到：

| 项目 | 结果 |
| --- | ---: |
| 过滤评分图片 | 4,070 |
| 过滤投票 | 136,943 |
| 官方 ZIP 中图片 | 5,101 |
| 无过滤评分、已排除图片 | 1,031 |
| 已解压训练候选图片 | 4,070 |
| 图片总字节数 | 567,108,028 |
| 唯一 SHA-256 | 4,070 |
| 重复 SHA-256 组 | 0 |

官方图片包覆盖全部 4,070 个评分 ID，但另含 1,031 张没有出现在
`votes_filtered.csv` 的图片。它们没有弱标签，未解压到训练图片目录；
完整 ID 记录在 `data/manifests/eva/excluded_unrated.json`。

有 3 张图片缺少常见的 JPEG `FFD9` 结束标记：`1649.jpg`、
`5298.jpg`、`696581.jpg`。三张均有 JPEG 文件头，并已用 Windows
图像解码器成功打开；图片清单仍以 `has_eoi_marker=false` 显式标记，
训练前应由实际训练解码器再做一次全量可读性检查。

## 授权边界

事实：作者公开提供数据和下载方式，并要求使用者引用论文；仓库中未见
标准许可证文件或明确商业授权条款。

本项目决策：按用户指定的研究用途采集，清单写
`research_only=true`。这不是商业许可结论；商业运行仍必须重新核对
EVA 与原始 AVA 图片的权利边界。

## 采集约束

- 仅访问公开 HTTPS 文件，不登录、不绕过验证。
- 顺序请求，默认请求间隔 1 秒，有限重试。
- 验证页、403、429 或非 HTTPS 重定向立即停止。
- 原始响应、URL、时间、大小和 SHA-256 写入 capture 清单。
- ZIP 先检查路径、扩展名、重复 ID 和评分图缺失，再解压。
- 无评分图片不进入格式化图片清单。

## 为什么先选 EVA

当前任务需要同时学习照片美学和技术质量。纯美学数据集只能提供总体
审美分，纯 IQA 数据集只能提供技术质量分；把两种数据拼在一起会引入
图片域和标注协议差异。EVA 在同一批图片、同一批投票中同时给出两类
信号，虽然规模只有 4,070 张，却最适合先验证双头训练和字段映射。

这只是第一批数据，不代表后续不再补充更大的纯美学或纯技术数据集。
